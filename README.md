# Падел77 — Match Point

Независимая презентационная концепция: видео на первом экране, интерактивный выбор формата и демонстрационная форма записи из исходной версии main.

Запуск: `python -m http.server 8012` из корня проекта. Откройте страницу в браузере. Форма демонстрационная и не отправляет данные. Цены и расписание не подключены. Встроенное видео и постер взяты из предыдущего концепта; локальные шрифты и лицензии находятся в assets/fonts.

## Установка как PWA

Для установки нужен опубликованный сайт по HTTPS (для локальной разработки также подходит localhost). Android: в поддерживаемом браузере используйте кнопку «Установить приложение» внизу страницы или меню браузера. iPhone/iPad: в Safari нажмите «Поделиться» → «На экран Домой» → «Добавить». Браузер и настройки устройства влияют на доступность установки.

После первого посещения основные файлы сохраняются для просмотра без сети. Видео может быть недоступно офлайн, вместо него показывается статичный кадр. Данные расписания и бронирования остаются демонстрационными и не отправляются; для актуальной информации нужно подключение к интернету. Не храните в кэше данные будущей реальной записи. При изменении списка файлов PWA обновите версию кэша в `sw.js` и проверьте повторное открытие после обновления.
