# Падел77 — презентационный концепт

Статическая презентационная версия сайта. Графитово-зелёная палитра, шампань, локальные Manrope и Cormorant Garamond, векторная графика ракетки и корта.

Откройте `index.html` в браузере или запустите из папки проекта:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Сборка и установка зависимостей не требуются. Сохраняйте папку `assets` рядом с HTML: она содержит стили, шрифты и их лицензии.

Запись работает в демонстрационном режиме: расписание генерируется, данные формы не отправляются. Цены, контакты и биографии перенесены из исходного концепта и не сверены с действующим сайтом клуба. Перед публикацией требуется подключение реального расписания и согласование контента.

Проверено в Chromium при ширинах 1440, 390 и 360 px: отсутствие горизонтального переполнения, локальная загрузка шрифтов, переход к записи, выбор занятия, демонстрационное подтверждение и окно тренера.
