# Падел77 — Match Point

Независимая презентационная концепция: видео на первом экране, интерактивный выбор формата и демонстрационная форма записи.

Запуск: `python -m http.server 8012` из корня проекта. Откройте страницу в браузере. Форма демонстрационная и не отправляет данные. Цены и расписание не подключены. Встроенное видео и постер взяты из предыдущего концепта; локальные шрифты и лицензии находятся в assets/fonts.
